Ein privater KI- und Automatisierungs-Stack auf einem einzigen VPS

Selbst gehostetes Modell-Serving, eine Chat-Oberfläche, eine Automatisierungsplattform und ein autonomer Agent auf einem kleinen Server.

Problem

Ich wollte ein Labor, in dem ich KI-gestützte Automatisierung testen konnte, ohne Firmen- oder persönliche Daten an Drittanbieter zu senden und ohne eine monatliche Rechnung pro Tool.

Vorgehen

Alles läuft als Container auf einem VPS, verwaltet über Portainer, hinter einem Reverse Proxy. Lokales Modell-Serving für kleine Aufgaben, eine Aggregationsschicht für externe Free-Tier-Anbieter, wo ein größeres Modell nötig ist, eine Web-Chat-Oberfläche darüber und eine Automatisierungsplattform, die der Agent steuern kann.

Lösung

Der Stack umfasst lokales Modell-Serving, ein Web-Chat-Frontend, einen API-Aggregationsdienst, eine Automatisierungsplattform und einen autonomen Agenten, der mit einer Messaging-App verbunden ist, damit Aufgaben vom Telefon gesendet werden können.

Ergebnis

Ein funktionierendes privates Labor, das jetzt der Ort ist, an dem jede Automatisierungsidee prototypisiert wird, bevor sie in die Nähe von Produktion kommt.

Was ich gelernt habe

  • Free-Tier-Modellanbieter unterscheiden sich enorm im Durchsatz. Für Agenten-Workloads zählt Tokens pro Sekunde mehr als Benchmark-Werte.
  • Führe Experimente auf einem persönlichen VPS aus, nicht auf Firmeninfrastruktur. Das hält den Explosionsradius und die Compliance-Frage einfach.
