A private AI and automation stack on a single VPS

Self-hosted model serving, a chat interface, an automation platform and an autonomous agent on one small server.

Problem

I wanted a lab where I could test AI assisted automation without sending company or personal data to third party services, and without a monthly bill per tool.

Approach

Everything runs as containers on one VPS, managed through Portainer, behind a reverse proxy. Local model serving for small tasks, an aggregation layer for external free tier providers where a bigger model is needed, a web chat interface on top, and an automation platform that the agent can drive.

Solution

The stack includes local model serving, a web chat frontend, an API aggregation service, an automation platform and an autonomous agent connected to a messaging app so tasks can be sent from a phone.

Result

A working private lab that is now the place where every automation idea gets prototyped before it goes anywhere near production.

What I learned

  • Free tier model providers differ enormously in throughput. For agent workloads, tokens per second matters more than benchmark scores.
  • Run experiments on a personal VPS, not on company infrastructure. It keeps the blast radius and the compliance question simple.
