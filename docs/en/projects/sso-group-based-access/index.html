Single sign-on with group based access to a file platform

Connected a self-hosted file platform to a central identity provider so that group membership, not manual assignment, controls access.

Problem

Access to shared folders was assigned per user by hand. Every new colleague meant a manual round of permission setting, and every departure meant hoping nobody forgot one.

Approach

Centralize identity: the file platform authenticates against the identity provider, and folder access follows group membership that already exists in the directory.

Solution

Social login integration between the file platform and the identity provider, with group mapping so access is granted and revoked by group membership. Separately, I reviewed and tightened the policy for anonymous sharing links on the corporate file platform.

Result

Onboarding and offboarding became a group membership change instead of a manual permission review.

What I learned

  • Permissions that are assigned per user are permissions that will eventually be wrong. Map them to groups.
  • Anonymous sharing links are the quiet data leak in most organizations. Set the policy deliberately, do not accept the default.
