خانه پروژه‌ها درباره

یک ربات پیام‌رسان که ویدیوها را به زبان خودت خلاصه می‌کند

یک لینک ویدیو در یک برنامه چت بفرست، یک خلاصه مفید بگیر، کاملاً از طریق REST API پلتفرم اتوماسیون ساخته شده است.

مسئله

یک ابزار شخصی می‌خواستم که ویدیوهای فنی طولانی را در چند دقیقه به چیزی خوانا تبدیل کند، به زبان خودم.

رویکرد

زنجیره عمداً ساده است: تریگر پیام، استخراج شناسه ویدیو، اعتبارسنجی لینک، دانلود زیرنویس، حذف تگ‌های زمان و قالب‌بندی، ارسال متن تمیز با یک پرامپت خلاصه‌سازی به مدل زبانی، پاسخ در چت. اجازه دادم عامل آن را مستقیماً در برابر REST API پلتفرم اتوماسیون بسازد نه از طریق یک لایه پروتکل میانی، چون مسیر API همانی است که خطاهایش را واقعاً گزارش می‌کند.

راه‌حل

یک ربات کارا با مدیریت خطا، به علاوه یک الگوی قابل استفاده مجدد برای اینکه یک عامل ورک‌فلوها را برنامه‌ای ایجاد و فعال کند.

نتیجه

شخصاً استفاده می‌شود، و مهم‌تر: الگویی تولید کرد برای اینکه اکنون چگونه به عامل‌ها اجازه می‌دهم اتوماسیون بسازند: با REST API صحبت کن، اول اعتبارنامه‌های موجود را بررسی کن، در خطا خوداصلاح کن، فعال کن، سپس یک تست واقعی اجرا کن.

چیزی که یاد گرفتم

  • وقتی یک عامل زیرساخت می‌سازد، رابطی با واضح‌ترین پیام‌های خطا به او بده. قابلیت اشکال‌زدایی بر ظرافت پیروز است.
  • ایجاد اعتبارنامه همان یک قدمی است که معمولاً قابل خودکارسازی نیست. ورک‌فلو را طوری طراحی کن که این قدم یک بار، از قبل، اتفاق بیفتد.
