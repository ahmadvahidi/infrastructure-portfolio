A messaging bot that summarizes videos in your own language

Send a video link in a chat app, get a useful summary back, built entirely through the automation platform's REST API.

Problem

I wanted a personal tool that turns long technical videos into something readable in a few minutes, in my own language.

Approach

The chain is deliberately simple: message trigger, extract the video id, validate the link, download the subtitle track, strip the timing and formatting tags, send the clean text to a language model with a summarization prompt, reply in the chat. I had the agent build it directly against the automation platform's REST API rather than through an intermediate protocol layer, because the API path is the one that actually reports its errors.

Solution

A working bot with error handling, plus a reusable pattern for having an agent create and activate workflows programmatically.

Result

Used personally, and more importantly it produced the template for how I now have agents build automations: talk to the REST API, check existing credentials first, self correct on error, activate, then run a real test.

What I learned

  • When an agent builds infrastructure, give it the interface with the clearest error messages. Debuggability beats elegance.
  • Credential creation is the one step that usually cannot be automated. Design the workflow so that step happens once, up front.
